## What we did not check, and should

- **Whether schools in our target geography actually enrolled in ESU.** The $1 price is published;
  uptake is not. A school that never enrolled is already unpatched today, which is a different and
  more urgent conversation than the one this folder assumes.
- **Regional pricing.** All figures are USD from Microsoft US-facing pages. A UK or Indian school's
  numbers will differ, and spec §1's flagship example is a Marathi-locale school.
- **Whether refurbishers have already solved this.** The wedge in
  [`03-analysis/the-wedge.md`](../03-analysis/the-wedge.md) assumes they have not. That assumption has
  not been tested against a single refurbisher, and testing it needs a human (§9).

Each of these would change the plan if it came back differently. None of them is expensive to check.
They are listed again as the first three items in [`04-plan/30-60-90.md`](../04-plan/30-60-90.md).
