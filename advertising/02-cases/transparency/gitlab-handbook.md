## The format point

GitLab's handbook is not a blog and not a marketing site. It is **the actual operating document**,
published as-is, with the awkward parts intact.

The distinction matters because the credibility comes entirely from it being unretouched. A curated
"culture page" derived from an internal handbook is a different artifact and produces none of the same
effect — readers detect the curation and correctly discount it.

## The test for us

We have four documents that would qualify: `DECISIONS.md`, `BLOCKED.md`, `PROGRESS.md`, `GATE.md`.

The test is whether we would publish them **without editing a single line**. If the answer is yes, they
are the asset. If we find ourselves wanting to soften `BLOCKED.md` B9 (*"the $0 tier has no product any
more"*) or `GATE.md`'s *"Not proven, and not claimed"*, then what we would be publishing is marketing
wearing a handbook's clothes, and it will be read that way.

Right now the answer is yes for all four, which is a genuinely unusual position and is worth not losing.
