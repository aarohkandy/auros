Safety Read this before the download

What can go wrong.

AurOS has been tested on simulated machines and its installer has run on real Windows in CI. It has been installed on 0 real PCs. Here is what we know can go wrong, what AurOS does about it, and what does not come across from Windows.

First

  1. Back up anything you cannot lose. To a USB stick or another computer, before you run it. This is pre-release software and the first real PCs are the test.
  2. Plug it in. On battery it stops: Plug it in and try again.
  3. Expect a warning from Windows. The installer is not signed yet, so Windows SmartScreen warns before it opens it.
  4. Shut Windows down properly first. From the Start menu, not by holding the power button.

If something goes wrong

The installer checks before it changes anything, and refuses rather than guess. These are its own words, from src/aurstage/install.c.

IfAurOS says, and does
The power goes in the middleCut on purpose at 18 named instants in testing, and Windows came back from every one: 138 of 138 checks. On a simulated disk, with the earlier design that starts from a memory stick: a real drive that lies about having flushed its cache is a property of that drive, and is not tested.
Windows was not shut down properly, or is hibernated (Fast Startup)AurOS cannot tell whether this Windows drive was closed down properly. Start Windows, shut it down from the Start menu, and try again. Nothing is changed.
The drive is failingCopy your files onto a USB stick today and have the drive replaced. It reads every sector of the space it would use before it uses it.
The drive is encrypted by other softwareThat has to be turned off and the drive decrypted first.
The computer is not the one the installer looked atThis is not the computer the installer was prepared for. It refuses.
Its firmware is unusualTested on one firmware (OVMF), with Secure Boot on. A 2014 laptop’s firmware is not that. The installer’s check runs first and writes nothing.
You don’t like itChoose No, go back to Windows on the first start, or Put Windows back from AurOS’s start-up menu. Windows comes back as it was. Until you press Yes, it all works, switching on still starts Windows.

What doesn’t come across

True for every move from Windows, not only this one. The list AurOS shows after the first start is the same list, from src/ferry/ferry-report.

  • Windows programsThey were built for Windows and do not run here. Not Office, not Photoshop, not the program that came with the printer. Use the web version or a Linux one.
  • Saved passwords and cookies in Chrome and EdgeLocked to your Windows sign-in, and AurOS cannot unlock them yet. Sign in to the browser again and let it sync.
  • Windows Credential Manager entries, remote desktop and app tokensEncrypted to your Windows login and unrecoverable offline.
  • Wi-Fi passwordsNot yet: the network names come across, the passwords have to be typed once.
  • OneDrive files that are online-onlyThey live on the server, not the disk. Download them in OneDrive first.
  • Files on a locked BitLocker drive, or encrypted with EFSUnreadable until unlocked in Windows.
  • Films, books and music with DRMLicensed to the old machine.
  • Windows Hello: PIN, fingerprint, faceSealed to this PC’s security chip.
  • DriversLinux supplies its own.

What does

Your Documents, Pictures, Music, Videos, Desktop and Downloads. The whole Firefox profile, saved passwords included (the test build ships GNOME Web, not Firefox, so the profile waits until Firefox is installed). Your wallpaper, keyboard layout, language and time zone. The Windows drive is only ever read, never written, while that happens.
