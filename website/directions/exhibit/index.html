The way back

Conservators work to one rule: whatever you do to an object must be reversible. Until you tell AurOS it works, switching the PC on still starts Windows, and “Put Windows back” returns it exactly as it was.

    1. 1Real PCs whose drive AurOS has resized and written so far: 0. Every install to date is on simulated machines under real UEFI firmware with Secure Boot on; the Windows half of the installer runs on a real Windows machine on every change. A spare PC is the next piece of evidence.
    2. 2The power-cut run used one firmware (OVMF), one virtual disk and a memory stick (v3). It tests the order in which writes reach the disk and that each commit is a single sector; it says nothing about a particular drive’s cache or a failing battery.
